ФИГ. 2

Каталог скилов

bff-pipeline-v2

Дирижёр + runner: preflight, run, verify, resume по fingerprint, тесты

bff-schema-create-v2

Этап 1 — .gql схема query/mutation по канону graph/{domain}/

bff-datasource-create-v2

Этап 2 — DataSource к микросервису, ошибки через ApiDataSourceError

bff-resolver-create-v2

Этап 3 — резолвер (+ трансформер), регистрация в resolvers.ts

bff-e2e-verify-v2

Этап 4 — e2e против BFF Target после сверки identity схемы

client-types-sync-v2

Этап 5 — codegen типов клиента из живой схемы BFF

client-apollo-create-v2

Этап 6 — Apollo query/mutation файлы с type-check и eslint

bff-pipeline-bff

Агент BFF-стороны: ведёт этапы 0–4, передаёт эстафету client-агенту

bff-pipeline-client

Агент клиентской стороны: этапы 5–6 c --from-stage 5

realt-flow

ФИГ. 3

Агенты

bff-pipeline-bff

этапы 0–4

Preflight с вопросом об обновлении api-schema, генерация схемы, DataSource и резолвера, e2e против живого BFF. После PASS этапа 4 передаёт работу дальше.

claude agentopencode agentcursor rule

bff-pipeline-client

этапы 5–6

Codegen типов клиента со сверкой SHA-256 схемы, создание Apollo-файлов. Type-check смотрит только на apolloPath, чужие падения tsc этап не валят.

claude agentopencode agentcursor rule

realt-flow

флоу задачи целиком

Скрипты вместо ручного git/glab: сторя из YouTrack, фича-ветка от свежего stage, draft-MR, таск-ветки и их MR. Push в stage запрещён — guard в скриптах.

claude skillopencode agentcursor rule
ФИГ. 4

Установка

# дирижёр + runner
npx skills add git@github.com:egor1991egorovmac-eng/ai-agents-and-skills.git -g --skill bff-pipeline-v2

# агент BFF-стороны (этапы 0–4)
npx skills add git@github.com:egor1991egorovmac-eng/ai-agents-and-skills.git -g --skill bff-pipeline-bff

# агент клиентской стороны (этапы 5–6)
npx skills add git@github.com:egor1991egorovmac-eng/ai-agents-and-skills.git -g --skill bff-pipeline-client

# realt-flow: сторя → фича-ветка → таск-ветки → MR
npx skills add git@github.com:egor1991egorovmac-eng/ai-agents-and-skills.git -g --skill realt-flow

# stage-скилы этапов 1–6 — одной командой
npx skills add git@github.com:egor1991egorovmac-eng/ai-agents-and-skills.git -g \
  --skill bff-schema-create-v2 --skill bff-datasource-create-v2 --skill bff-resolver-create-v2 \
  --skill bff-e2e-verify-v2 --skill client-types-sync-v2 --skill client-apollo-create-v2
ФИГ. 5

Контракт runner

СтатусExitЧто делает агент
PASS0 Следующий этап сразу, без подтверждения. Полный лог не загружается
FAIL1 Чинит продуктовый код по checks[].detail и повторяет тот же этап. Override запрещён
BLOCKED2 Сообщает пользователю; продолжение только после явного override или --confirm apply
